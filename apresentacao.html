Orientações para acesso

Qual código devo usar?

O professor fornece os códigos. Na área do aluno, siga a orientação correspondente à sua situação.

🔑

1. Token da avaliação

É o código principal, necessário para identificar a avaliação. Dentro do prazo, use o token para iniciar normalmente.

⏰

2. Entrada atrasada

Se ainda não começou e o prazo terminou, solicite ao professor um código individual de entrada atrasada. Ele não substitui o token.

🔄

3. Recuperação

Se já começou e a prova travou, fechou ou foi atualizada, solicite o código individual de recuperação para continuar sem reiniciar a avaliação.

Os códigos especiais dependem da autorização do professor e das verificações na área do aluno. Esta página é apenas informativa.
